- Built-ins to confirm: fzero(f, [xl xu]) (needs a sign change) or fzero(f, x0); roots([a_n ... a_0]) for polynomials;
  fminbnd(f, a, b) for a minimum; a maximum of f = minimum of -f. Plot f first to choose brackets.
- Bisection iterations for an absolute error Ead: n = ceil(log2((xu - xl)/Ead)).
- Newton-Raphson needs f'(x): write it analytically (df = @(x) ...).
- Maximum deflection/optimum: solve dy/dx = 0 (write dy/dx analytically), then evaluate y there.
- Given y = f(x) and a target value Y, solve f(x) - Y = 0 (e.g. tank volume = 30 m^3).

CHEATSHEET:
- Function f(x) on [a,b]: integ_trap(f,a,b,n) (n segments, h = (b-a)/n), integ_simp13(f,a,b,n) (n even; n = 2 is the single
  application), integ_simp38(f,a,b,n) (n multiple of 3), integ_newtoncotes(f,a,b,'trap'|'simp13'|'simp38'|'boole') (single),
  [q,ea,iter,R] = integ_romberg(f,a,b,es) (es in %), integ_gauss(f,a,b,npts) (2..6 points).
  Reference value: integral(f,a,b) (vectorized f: use .* ./ .^), integral2(f,xa,xb,ya,yb) for double integrals.
- Tabulated data (x,y): trapz(x,y) (unequal spacing ok), cumtrapz(x,y) running integral, integ_simpdata(x,y) Simpson
  for equal spacing (odd segments -> 3/8 rule on the last three).
- Step size h -> n = round((b-a)/h). True percent relative error: et = abs((Itrue - I)/Itrue)*100.
- Work with varying force and angle: W = trapz(x, F.*cos(theta)). Force on a dam: P = trapz(z, rho*g*w.*(D - z));
  line of action d = trapz(z, rho*g*z.*w.*(D - z))/P (height above the bottom).
- Average value of f on [a,b]: integral/(b - a). Average concentration: trapz(z, c.*A)/trapz(z, A).
- Mass from density and area: trapz(x, rho.*Ac) (watch units: g/cm^3 * cm^2 * cm).
